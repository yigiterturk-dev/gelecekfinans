# Altın kotasyonunda kaynak atfı

Altın fiyatı verisi Yahoo Finance kotasyonu yoksa CoinGecko XAUT yedeğine düşebilir. Kaynak seçimi artık `GoldPrice` yanıtında taşınıyor; CoinGecko kullanıldığında altın hesaplama aracı, altın hub ve altın detay sayfası görünür bir "Data provided by CoinGecko" bağlantısı gösteriyor. Fiyat API yanıtı da kaynak ve kotasyon zamanını içeriyor.

Kaynak: CoinGecko API kullanım sayfasındaki atıf talebi: https://www.coingecko.com/en/api. Test veya derleme çalıştırılmadı.
