# Altın Yahoo kotasyon kaynağını gösterme

Altın hub ve detay sayfası artık Yahoo Finance `GC=F` kotasyonu kullanıldığında kaynağı açıkça gösteriyor. CoinGecko yedek akışında mevcut CoinGecko bağlantılı atıf korunuyor; araç ve sunucu fiyat nesnesi de kaynağı zaten taşıyor.

Test veya derleme çalıştırılmadı.
