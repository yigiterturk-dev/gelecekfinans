# Kripto ticker hareket kontrolü

Sabit piyasa şeridine klavyeyle erişilebilen kaydırmayı durdur/sürdür düğmesi eklendi. Tekrarlanan ikinci coin dizisi ekran okuyuculardan gizlendi; ticker tek bir adlandırılmış bölge olarak sunuluyor. Sistem düzeyindeki azaltılmış hareket tercihi mevcut CSS kuralıyla çalışmaya devam ediyor.

Doğrulama: `git diff --check` temiz. Test/build çalıştırılmadı.
