# Site Ayarları yükleme ve kayıt geri bildirimi

Ayarlar ekranı artık yalnızca başarılı HTTP yanıtını ve beklenen JSON yapısını forma alıyor. GET hatasında varsayılanlarla sessizce düzenleme açılmıyor; tekrar dene ve oturum aç bağlantısı gösteriliyor. PATCH ağ/HTTP/yanıt hatalarında "Kaydedildi" durumu verilmiyor ve kaydetme düğmesi hata sonrasında tekrar kullanılabiliyor.
