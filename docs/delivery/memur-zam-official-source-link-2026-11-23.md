# Memur zammı resmi kaynak bağlantısı

Memur zammı hesaplayıcısındaki açıklama, 2026–2027 sözleşme oranlarını duyuran Çalışma ve Sosyal Güvenlik Bakanlığı sayfasına bağlandı. Dönem sabitleri (2026: %11/%7, 2027: %5/%4) bu Bakanlık duyurusuyla karşılaştırıldı ve mevcut kodla uyumlu bulundu.
