# Kira hesaplayıcısında kaynaksız oran varsayımını kaldırma

Otomatik TÜFE oranı alınmadığında kira artış alanı artık varsayımsal `%30` ile dolmuyor; boş başlıyor ve kullanıcıya yenileme ayına ait TÜİK 12 aylık ortalama oranını girmesi gerektiği söyleniyor. Böylece kaynak verisi yokken hesaplayıcı keyfî oranı güncel tavan gibi sunmuyor.

Test veya derleme çalıştırılmadı.
