# Kurumsal sayfa sitemap tarihleri

Sitemap'te `lastModified` değerleri içerik değişiklikleriyle eşleştirildi. Gizlilik, çerez, hakkında, yayıncılık ilkeleri ve yazarlar sayfaları 23 Kasım 2026'da güncellendi; iletişim ve kullanım koşulları son düzenleme tarihlerini koruyor. Böylece değişmeyen sayfalara toplu şekilde yeni tarih verilmedi.

Değişikliklerin kanıtı mevcut çalışma ağacındaki sayfa diff'leridir. `git diff --check` temiz; test/build çalıştırılmadı.
